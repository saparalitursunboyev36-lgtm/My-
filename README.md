# 5-lesson (Next.js App Router)

## Ishga tushirish

```bash
npm install
npm run dev
```

So'ng http://localhost:3000 ni oching.

## Tuzilma

- `src/app/layout.jsx` — umumiy layout (Header + metadata)
- `src/app/page.jsx` — bosh sahifa (`/`)
- `src/app/about/page.jsx` — `/about`
- `src/app/contact/page.jsx` — `/contact`
- `src/app/products/page.jsx` — `/products`
- `src/app/products/privacy/page.jsx` — `/products/privacy`
- `src/app/loading.jsx` — yuklanish holati
- `src/app/not-found.jsx` — 404 sahifa
- `src/components/Header.jsx` — navigatsiya (Link bilan)
